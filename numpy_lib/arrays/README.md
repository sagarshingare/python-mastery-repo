---

## Running Demonstrations

Run all Array demonstrations:
```bash
python3 -m numpy_lib.arrays.run_examples --demo all
```

Or target individual operations:
```bash
python3 -m numpy_lib.arrays.run_examples --demo creation
python3 -m numpy_lib.arrays.run_examples --demo slicing
python3 -m numpy_lib.arrays.run_examples --demo manipulation
```
