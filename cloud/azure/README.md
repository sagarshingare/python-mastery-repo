# Microsoft Azure Data Architecture

> **Learning Path**: [Stage 09: Cloud Platforms & Warehouses](file:///Users/sagarshingare/Documents/python-mastery-repo/LEARNING_PATH.md#stage-09-cloud-platforms--warehouses) ▸ **Step 9.2: Azure Ecosystem**

Architecture guidelines for enterprise Azure data platforms:
- **Azure Data Lake Storage Gen2 (ADLS Gen2)**: Hierarchical namespaces, POSIX ACLs.
- **Azure Synapse Analytics**: Dedicated SQL pools, serverless queries, integrated Spark.
- **Azure Data Factory (ADF)**: Orchestration pipelines, copy activities, integration runtimes.
