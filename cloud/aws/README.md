# Amazon Web Services (AWS) Data Architecture

> **Learning Path**: [Stage 09: Cloud Platforms & Warehouses](file:///Users/sagarshingare/Documents/python-mastery-repo/LEARNING_PATH.md#stage-09-cloud-platforms--warehouses) ▸ **Step 9.1: AWS Ecosystem**

Architecture guidelines and data engineering patterns for AWS:
- **S3 Data Lake**: Storage tiering, bucket policies, lifecycle transitions.
- **AWS Glue**: Data Catalog, schema discovery crawlers, serverless ETL.
- **Amazon Athena**: Interactive serverless Presto/Trino queries over S3.
- **AWS Lambda**: Event-driven micro-batch ingestion and file trigger pipelines.
