# Snowflake Data Cloud

> **Learning Path**: [Stage 09: Cloud Platforms & Warehouses](file:///Users/sagarshingare/Documents/python-mastery-repo/LEARNING_PATH.md#stage-09-cloud-platforms--warehouses) ▸ **Step 9.4: Snowflake Data Cloud**

Cloud data warehousing with Snowflake:
- **Separation of Compute and Storage**: Elastic multi-cluster virtual warehouses (X-Small to 6X-Large).
- **Micro-Partitioning**: Automatic columnar compression and query pruning without explicit indexing.
- **Zero-Copy Cloning**: Instant testing environments without duplicated storage footprint.
- **Streams & Tasks**: Native Change Data Capture (CDC) and scheduled orchestration.
