# Metaclasses

> **Learning Path**: [Stage 01: Core Python Mastery](file:///Users/sagarshingare/Documents/python-mastery-repo/LEARNING_PATH.md#stage-01-core-python-mastery) ▸ **Step 1.10: Metaclasses**

Examples of Python metaclass patterns for class customisation at creation time.

## Topics covered

- `AttributeTrackerMeta` — track class attribute definitions
- Singleton metaclass pattern
- Validation metaclass — enforce interface contracts on subclasses

## Run examples

```bash
python -m core_python.metaclasses.run_examples
python -m core_python.metaclasses.run_examples --module tracker
python -m core_python.metaclasses.run_examples --module singleton
python -m core_python.metaclasses.run_examples --module validation
```
