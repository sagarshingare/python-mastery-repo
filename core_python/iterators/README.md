# Iterators

Custom iterator implementations and utility functions.

## Topics covered

- `RangeIterator` — custom iterator for numeric ranges
- `PeekableIterator` — look ahead one value without consuming
- `take()` — return the first *n* items from any iterable
- `pairwise()` — yield successive overlapping pairs

## Run examples

```bash
python -m core_python.iterators.run_examples
python -m core_python.iterators.run_examples --module range
python -m core_python.iterators.run_examples --module peekable
```
