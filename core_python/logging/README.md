# Logging

> **Learning Path**: [Stage 01: Core Python Mastery](file:///Users/sagarshingare/Documents/python-mastery-repo/LEARNING_PATH.md#stage-01-core-python-mastery) ▸ **Step 1.12: Production Logging**

Structured logging utilities and best practices for production Python.

## Topics covered

- `setup_logger()` — configurable console + file logger
- `log_scope()` — context manager for entry/exit logging
- `time_execution()` — decorator that logs function duration

## Run examples

```bash
python -m core_python.logging.run_examples
python -m core_python.logging.run_examples --module basic
python -m core_python.logging.run_examples --module file
python -m core_python.logging.run_examples --module scope
python -m core_python.logging.run_examples --module timed
```
