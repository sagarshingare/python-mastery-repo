# Streaming Pipeline Project

Real-time streaming pipeline architecture blueprint for ingesting, transforming, and persisting low-latency event streams.

## Features

- Event stream schema ingestion
- Tumbling and sliding window aggregations
- Watermarking for handling out-of-order late events
- Sinks to analytical storage and message queues
