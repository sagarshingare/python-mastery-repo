# Data Quality Framework Project

Declarative data validation framework inspired by Great Expectations and SodaSQL.

## Features

- Column-level assertions: nullity, uniqueness, range bounds, regex patterns
- Automated anomaly and schema drift alerts
- JSON quality test report generation
